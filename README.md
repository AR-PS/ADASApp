# ADASApp
Advanced Data Assimilation System based on JEDI

### Currently supported platforms
-   NOAA RDHPCS Hera
-   NOAA RDHPCS Jet
-   NOAA RDHPCS Orion
-   NOAA RDHPCS Hercules
-   NOAA RDHPCS Gaea (C5 and C6)
-   NOAA WCOSS2
